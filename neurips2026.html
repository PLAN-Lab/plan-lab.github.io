Toward Cognitive Supersensing in Multimodal Large Language Models

Visual imagery for multimodal cognition

Cognitive Supersensing introduces a Latent Visual Imagery Prediction head that learns internal visual reasoning chains alongside answer prediction. Reinforcement learning then grounds text reasoning in these visual latents, with CogSense-Bench evaluating five cognitive dimensions.

RAVEL: Rare Concept Generation and Editing via Graph-driven Relational Guidance

Rare-concept image generation and editing

RAVEL retrieves compositional, symbolic, and relational context from knowledge graphs to guide rare-concept generation and image editing without retraining the diffusion model. A self-correction module iteratively refines prompts using alignment feedback to improve attribute accuracy and narrative coherence.

Tiny but Trusted: Efficient Vision-Language Reasoning for Time-Series Anomaly Detection

Efficient, grounded time-series anomaly reasoning

VisAnomReasoner detects and localizes anomalies in time-series plots and explains the evidence supporting each decision. The compact vision-language model is trained with visually grounded reasoning on VisAnomBench, connecting unusual patterns to specific time intervals.

ELSA3D: Elastic Semantic Anchoring for Unified 3D Understanding and Generation

Elastic grounding for unified 3D understanding and generation

ELSA3D uses sparse Anchor Tokens to link language tokens to geometric evidence at the relevant scale. A joint router controls anchor selection, geometric scale, block execution, and MLP width, strengthening language–geometry grounding while reducing computation.

SILSA: Sliding-Window Slice Latents for Topology-Preserving High-Resolution 3D Generation

Compact slice latents for topology-preserving 3D generation

SILSA generates high-resolution 3D shapes from a single image using compact slice-based representations. Overlapping slices across three axes preserve thin structures, holes, and connectivity while substantially reducing the number of tokens.

LIBERO-MAX: Do Robot Policies Adapt When the World Changes?

Dynamic robustness of robot policies

LIBERO-MAX evaluates robot policies when the environment changes after action has begun. Matched Base and Dynamic rollouts share the task, reset, policy seed, and executed prefix, isolating whether task success is preserved after a persistent change.
